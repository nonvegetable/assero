# ASSeRO

ASSeRO (Authenticated, Scalable, Secure, randomized Registry Overlay) is a research prototype for a permissioned, randomized-committee ledger operated by geographically distributed government offices.

This repository implements a working research prototype spanning the Phase 1 local ledger and an in-memory distributed experiment layer. It provides deterministic transaction/state rules, Ed25519 authentication, append-only durable storage, deterministic committee selection, signed quorum certificates, offline message queues, incremental transaction synchronization, and seeded large-node simulation.

This is experimental infrastructure software, not a production system or a claim of suitability for the Government of India.

## Build and run

```bash
go test ./...
go test -race ./...
go build ./cmd/...

go run ./cmd/asserod --data ./data init
go run ./cmd/asserod --data ./data init --node-id RTO-A --listen :7000 --metrics :9090
go run ./cmd/asserod --config ./data/asserod.toml run
go run ./cmd/asserod --data ./data register \
  --vehicle-id VH-001 --vin ABC123 --registration MH01AA0001 \
  --owner-hash sha256:owner-a --rto RTO-MH-01 --type car
go run ./cmd/asserod --data ./data status
go run ./cmd/asserod --data ./data state --vehicle-id VH-001

go run ./cmd/asserod simulate --nodes 1000 --transactions 100 \
  --committee-size 15 --required-votes 10 --seed 42

go run ./cmd/asserod simulate --nodes 1000 --transactions 100 \
  --committee-size 15 --mode all --seed 42
```

The `run` command starts a long-running experimental node with persistent TCP peer transport. It serves `/health`, `/status`, and `/metrics` on the configured metrics address. See [DEPLOYMENT.md](DEPLOYMENT.md) for Docker Compose and multi-host setup.

The first command creates a local validator identity and durable ledger. The command is safe to repeat. Transaction signatures are generated by the local validator key and state transitions are validated before being committed.
